バッテリーの詳細

今のバッテリーはどれだけ蓄えられる？

現在の満充電容量と設計容量を比較し、システムが報告するバッテリーの状態、充放電回数、温度を確認できます。電源接続中は、電源と合意した供給電力の上限や入力電圧・電流も表示します。

残り時間は「概要」で確認できます。充電中は満充電までの時間を、放電中は十分な情報があれば、電源接続中でも残りの駆動時間を推定します。

電力とディスプレイの設定

屋外でコードを書き、蓋を閉じてもビルドを続ける。

スタンドアロン版では、この Mac で使える設定を「概要」から操作できます。

屋外での明るさ
対応する内蔵 XDR ディスプレイでは「HDRブースト」で明るさを引き上げられます。屋内に戻ったらオフにして消費電力を抑えられます。
蓋を閉じて実行
ビルドやダウンロードを始めてから「蓋を閉じて実行」をオンにします。バックグラウンドサービスが処理を継続し、オフにすると元のスリープ設定に戻ります。
充電と電力モード
「充電上限」を開いて目標値を選びます。手動で選んだ電力モードはバッテリー駆動時と外部電源接続時の両方に適用されます。

最大消費電力テスト

CPU と GPU の最大消費電力を個別に測る。

歯車メニューから「最大消費電力テスト」を開きます。CPU と GPU に同時に最長 60 秒の負荷をかけ、0.5 秒ごとに消費電力を更新し、それぞれの最大値を記録します。

チップの消費電力を取得できる Apple シリコン Mac のスタンドアロン版で使えます。途中で停止でき、最大値は次の測定またはアプリ終了まで残ります。

ターミナルで電力を読み取る

バッテリー状態、電力、残り時間を JSON 形式でスクリプトに渡したり、ターミナルからメニューバーの表示を切り替えたりできます。

コマンドの使い方 →
battervibe status --json
battervibe menu net
