Vibe Coding のために

アイデアを、もう少し遠くへ。

外出先での開発や長時間の作業、モバイル電源での使用中に、Macのバッテリー、電力、残り駆動時間の目安をメニューバーで確認できます。対応機種ではHDR輝度を上げられます。

エディタに集中したまま

Macの電力の状況を把握。

残量、入力電力、システムの消費電力、バッテリーの正味電力を確認できます。情報を取得できる場合は充電完了や残り駆動時間の目安を表示します。詳細画面では状態、充放電回数、温度などを確認できます。

入力電力はMacの接続端子で測定した直流の値です。取得できる項目は機種、macOS、電源状態によって異なります。

自然の中に、作業場所を

日差しの中でも、くっきりと。

景色を変えて、つくる時間を続けましょう。対応する画面の余裕ある輝度を使い、自然光の中でもコードやウェブサイトを見やすくします。

HDR 輝度ブースト
対応する XDR ディスプレイの余裕ある輝度を使い、明るい環境での見やすさを高めます。
必要なときにオン
明るさが足りないときに HDR をオンにし、室内に戻ったらオフにできます。

HDR は MacBook Pro（Mac14,6）の内蔵 XDR 画面で検証済みです。他の機種は未検証です。増光により消費電力が増える場合があります。

待ち時間は Mac に任せて

閉じても、作業の流れは続く。

ビルドもダウンロードも、まだ進行中。Mac を机の上で動かしたまま、戻ったところから続きを始められます。

プロジェクトのビルドダウンロード長時間の Agent タスク

フタを閉じた状態での実行には、Webサイトからのインストールで提供されるバックグラウンド機能とシステムの許可が必要です。作業終了後はメニューバーでオフにできます。

BatterVibe コントロールパネル

充電上限と購入を管理。

コントロールパネルで機能、動作条件、ターミナルの使い方を確認できます。Mac App Storeの1.1アップデートでは、体験、App内課金、購入の復元が追加されます。

充電上限

macOS 26.4以降を使用するAppleシリコン搭載の対応機種で目標を設定できます。ストア版のアップデートではAppleショートカットを使用します。

App内課金

高度な機能は14日間の無料体験、または買い切りのApp内課金で利用できます。

購入を復元

購入時と同じApple Accountを使用し、コントロールパネルで購入を復元します。

ターミナルで確認・操作

バッテリー残量、電力、推定駆動時間を確認できます。JSON をスクリプトで使い、メニューバー表示や HDR 増光など、対応する機能を操作できます。

コマンドラインの使い方 →
battervibe status --json
battervibe menu net

ダウンロードとバージョン

Mac App Storeで1.0を配信中。

中国本土のMac App Storeから1.0を無料で入手し、バッテリーと電力を確認できます。Webサイト経由の0.10.1は、ターミナルコマンドと駆動時間の目安、対応機種のHDR、フタを閉じた状態での実行、充電設定に対応しています。
