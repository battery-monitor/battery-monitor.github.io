Web Coding と Vibe Coding のために

アイデアを、もう少し遠くへ。

デスクから陽だまりへ。BatterVibe は Mac の消費電力を見えるようにし、屋外で画面を明るくし、長く続く開発作業を支えます。

使い方を見る↓開発中 · リリース状況

MacBook · macOS 13 以降 · 対応機能は機種とインストール経路によって異なります

電力をひと目で↓日差しの下でも見やすく↓画面を閉じても、作業は続く↓

01 / エディタに集中したまま

このビルド、どれくらい使ってる？

AI コーディング、ブラウザのプレビュー、ビルドとテスト。入力電力、Mac 全体の消費電力、バッテリーの正味電力をメニューバーに表示し、作業中も電力の状態を確認できます。

値は機種、macOS、電源状態によって変わります。Mac 全体の測定値であり、個別アプリの消費電力ではありません。

02 / 自然の中に、作業場所を

日差しの中でも、くっきりと。

景色を変えて、つくる時間を続けましょう。対応する画面の余裕ある輝度を使い、自然光の中でもコードやウェブサイトを見やすくします。

HDR 輝度ブースト
対応する XDR ディスプレイの余裕ある輝度を使い、明るい環境での見やすさを高めます。
必要なときにオン
明るさが足りないときに HDR をオンにし、室内に戻ったらオフにできます。

HDR は MacBook Pro（Mac14,6）の内蔵 XDR 画面で検証済みです。他の機種は未検証です。増光により消費電力が増える場合があります。

03 / 待ち時間は Mac に任せて

閉じても、作業の流れは続く。

ビルドもダウンロードも、まだ進行中。Mac を机の上で動かしたまま、戻ったところから続きを始められます。

プロジェクトのビルドダウンロード長時間の Agent タスク

閉じた状態での動作には、ウェブサイト経由のバックグラウンドコンポーネントとシステムの許可が必要です。Mac App Store 経由での対応は検証中です。風通しのよい固定した台で使ってください。

BatterVibe コントロールパネル

機能を知る。購入を復元する。

メニューバーでは電池残量と電力を確認。独立パネルには機能と対応条件の説明、購入の復元、そして BatterVibe を支えてくださる方への感謝をまとめます。
