Vibe Coding のための Mac メニューバーアプリ

Mac が重いときは、 どのコアが動いているか確認。

長時間のビルドやローカルモデルの実行中、モバイル電源で作業するときに、メニューバーで CPU の負荷、バッテリー残量、電力を確認できます。作業を続けながら電源が足りているか分かります。

直近 20 秒をコアごとに確認。

「概要」には現在の使用率が表示されます。ポインタを重ねるとヒートマップが開き、クリックすると固定できます。各行は CPU の 1 コアで、色が濃いほどその秒の稼働時間が長かったことを示します。

Apple シリコンの独立版では、高性能コアと高効率コアを分け、GPU 全体も表示します。CPU の行を選ぶと使用率とコア群の周波数、GPU の行では推定周波数を確認できます。取得できる場合は消費電力も表示されます。

バッテリーの詳細

いまの電源で足りているか分かる。

「概要」で入力電力、Mac の消費電力、バッテリーの正味電力を比較。正味電力が負ならバッテリーが不足分を補っています。情報がそろうと充電完了や残り駆動時間の目安も表示します。

「バッテリーの詳細」では、満充電容量と設計容量、状態、充放電回数、温度を確認できます。対応する電源では電力、電圧、電流も表示します。

電力とディスプレイの設定

屋外で見やすく、作業を続ける。

独立版の「概要」から輝度、蓋を閉じた状態での動作、充電、電力モードを調整できます。

屋外での明るさ
対応する内蔵 XDR ディスプレイでは「HDRブースト」で明るさを引き上げられます。屋内に戻ったらオフにして消費電力を抑えられます。
蓋を閉じて実行
ビルドやダウンロードを始めてから「蓋を閉じて実行」をオンにします。バックグラウンドサービスが処理を継続し、オフにすると元のスリープ設定に戻ります。
充電と電力モード
「充電上限」を開いて目標値を選びます。手動で選んだ電力モードはバッテリー駆動時と外部電源接続時の両方に適用されます。

最大消費電力テスト

CPU と GPU のピーク電力を測る。

歯車メニューから電力テストを開始すると、CPU と GPU に同時に最大 60 秒間負荷をかけます。0.5 秒ごとに計測し、両方のピーク値を記録します。

対応する Apple シリコン搭載 Mac の独立版で利用できます。途中で停止でき、結果は次の測定を開始するか App を終了するまで残ります。

ターミナルで電力を読み取る

バッテリーと電力の値を JSON でスクリプトに渡すほか、ターミナルからメニューバーの表示を切り替えられます。

コマンドの使い方 →
battervibe status --json
battervibe menu net

配布形態ごとの機能

スタンドアロン版 0.10.6

Apple シリコン搭載 Mac で CPU と GPU の使用率、稼働時の周波数、消費電力を表示します。対応機種では蓋を閉じた状態での動作、統一電力モード、電力消費の大きい App、ピーク電力テストも利用できます。

Mac App Store 1.1

中国本土で無料ダウンロード。電池と電力の確認、駆動時間の目安、ターミナルでの読み取りに対応。対応機種の HDR 輝度アップと充電上限は、14 日間無料で試すか、6 人民元で買い切りできます。
