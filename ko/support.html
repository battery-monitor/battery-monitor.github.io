지원

메뉴 막대에서 앱을 찾고 표시할 수치를 선택한 뒤 배터리와 전력 상태를 확인하세요.

개발자에게 문의

Mac 모델, macOS 버전, 앱 버전과 발생한 상황을 알려 주세요.

jiangzp.cs@icloud.com
앱을 실행한 뒤 어디에서 찾나요?

처음 실행하면 패널이 열립니다. 이후 메뉴 막대의 배터리 아이콘을 누르면 열립니다. 다시 누르거나 Esc 키를 누르면 닫힙니다.

언어를 바꾸려면 어떻게 하나요?

오른쪽 아래 톱니바퀴 메뉴에서 언어를 선택하세요. 8개 언어 또는 시스템 설정을 선택할 수 있으며 즉시 적용되어 Mac에 저장됩니다. 웹사이트 언어 메뉴도 현재 페이지에 해당하는 번역으로 이동합니다.

메뉴 막대의 표시를 바꾸려면?

패널 오른쪽 아래 톱니바퀴 메뉴의 표시 옵션에서 배터리 잔량, 입력 전력, 소비 전력 또는 순전력을 선택하세요.

전원 연결 중 순전력이 음수인 이유는?

순전력은 입력 전력에서 소비 전력을 뺀 값입니다. Mac의 소비량이 어댑터 공급량을 넘으면 배터리가 부족분을 보충합니다. 어댑터 정격 출력과 현재 직류 입력은 별개의 수치입니다.

수치 대신 —가 표시되는 이유는?

현재 Mac 모델, macOS 버전 또는 전원 상태에서 해당 수치를 제공하지 않는다는 뜻입니다.

새로 고침, 로그인 시 실행, 종료는 어떻게 하나요?

수치는 5초마다 자동으로 갱신됩니다. 톱니바퀴 메뉴에서 로그인 시 실행을 켜거나 앱을 종료할 수 있습니다. 자동 실행은 선택 사항입니다.

어떤 Mac을 지원하나요?

Mac App Store 버전은 macOS 13 이상이 필요하며 내장 배터리가 있는 MacBook을 위해 설계되었습니다. 데스크톱 Mac에서는 배터리 전용 수치를 사용할 수 없습니다.
