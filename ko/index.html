Web Coding과 Vibe Coding을 위해

아이디어를,조금 더 멀리.

책상에서 햇살 아래까지. BatterVibe는 Mac의 실시간 전력을 보여 주고, 야외에서 화면을 더 밝게 하며, 오래 걸리는 개발 작업을 이어갈 수 있도록 돕습니다.

작업 장면 살펴보기↓개발 중 · 출시 현황

MacBook · macOS 13 이상 · 지원 기능은 기기와 설치 경로에 따라 다릅니다

전력을 한눈에↓햇살 아래에서도 선명하게↓덮개를 닫아도 작업은 계속↓

01 / 편집기에 집중하면서

이번 빌드는 전력을 얼마나 쓸까요?

AI 코딩, 브라우저 미리보기, 빌드와 테스트는 모두 전력을 사용합니다. 입력 전력, 시스템 소비 전력, 배터리 순전력을 메뉴 막대에서 확인하세요.

수치는 기기, macOS, 전원 상태에 따라 달라집니다. Mac 전체 측정값이며 개별 앱의 소비 전력을 나타내지 않습니다.

02 / 자연 속에 마련한 작업 공간

햇살은 밝게, 화면은 선명하게.

새로운 풍경에서 만드는 즐거움을 이어가세요. 호환 화면의 추가 밝기를 활용해 자연광에서도 코드와 웹사이트를 편하게 볼 수 있습니다.

HDR 밝기 향상
호환 XDR 디스플레이의 추가 밝기 여유를 활용해 밝은 환경에서 보기가 편해집니다.
필요할 때 켜기
추가 밝기가 필요할 때 HDR을 켜고, 실내로 돌아오면 끌 수 있습니다.

HDR은 MacBook Pro(Mac14,6)의 내장 XDR 화면에서 검증했습니다. 다른 모델은 검증 대기 중이며, 밝기를 높이면 전력 사용이 늘 수 있습니다.

03 / 기다림은 Mac에 맡기세요

덮개를 닫고, 흐름은 이어가세요.

빌드도 다운로드도 아직 진행 중이라면, Mac을 책상 위에서 계속 실행해 두세요. 돌아와서 하던 일을 이어갈 수 있습니다.

프로젝트 빌드다운로드장시간 Agent 작업

덮개를 닫고 실행하려면 웹사이트 설치 경로의 백그라운드 구성 요소와 시스템 승인이 필요합니다. Mac App Store 경로의 일반 잠자기 방지는 덮개를 닫은 실행과 다릅니다. Mac은 통풍이 잘되는 고정된 표면에 놓으세요.

하나의 제품, 하나의 제어 패널

자주 쓰는 제어를 한곳에.

메뉴 막대에서는 빠르게 확인하고, 독립된 제어 패널에서는 전체 상태와 작업을 살펴봅니다. BatterVibe가 이 둘을 하나의 경험으로 연결합니다.

01

확인부터 제어까지

전력, 화면, 실행 상태를 명확히 구분하고 현재 작업에 필요한 제어를 선택하세요.

02

첫 14일 무료 체험

자신의 작업 환경에서 처음 14일 동안 무료로 체험할 수 있도록 준비하고 있습니다. 체험과 구매 연동은 개발 중입니다.

03

Apple에서 한 번 구매

중국 본토 기준 예정 가격은 CNY 6입니다. 자동 갱신 없이 한 번 구매하며, 패널에서 구입 항목을 복원할 수 있도록 준비 중입니다.

출시 현황

새로운 BatterVibe를 준비하고 있습니다.

현재 심사에 제출된 것은 이전 배터리 모니터링 버전입니다. 이 페이지의 새로운 기능, 독립 제어 패널, Apple 앱 내 구입은 개발 중이며 새 버전의 다운로드와 체험은 아직 제공하지 않습니다.

체험하고 결정하세요.

첫 14일 무료 체험 후 한 번 구매하는 방식입니다. 중국 본토 예정 가격은 CNY 6이며 자동 갱신하지 않습니다. 다른 지역 가격은 출시 후 Apple 구입 화면에서 확인할 수 있습니다.
