Where can I download BatterVibe, and what does it support?

Version 1.1 is available in the mainland China Mac App Store on macOS 13 or later. Per-core CPU activity starts with App Store version 1.2. Check the storefront for current availability. Battery details require a built-in battery. Supported Apple silicon Macs can view GPU activity, frequency, and wattage in the standalone edition.

How do I read the CPU heatmap?

Open Overview and hover over the activity percentage, or click to pin the heatmap. Each row tracks a core and each column is about a second. Deeper color means more busy time, and blank cells are gaps in the readings. History starts when you open Overview. The purple row in the standalone edition represents the entire GPU.

Why is net battery power negative when plugged in?

If your Mac draws more power than it receives, the battery covers the shortfall. A positive reading means net charging and a negative one means net discharging. Input power measures DC power at the Mac’s port. The charger’s rated wattage is a separate figure.

Where can I see runtime and battery health?

Overview shows time to full when charging and estimated runtime when discharging. Estimates change with the workload. A dash means there is too little information. Open Battery for capacity, health, cycles and temperature.

How do HDR boost and closed-lid operation work?

HDR boost requires a compatible built-in XDR display. The standalone app registers its background service at launch and reconnects automatically if the connection drops. This service keeps tasks running with the lid closed. If the switch requests approval, follow its link to Login Items & Extensions in macOS and then return to the app. Switching it off restores the previous sleep settings.

How do I set a charge limit?

On a compatible Apple silicon Mac running macOS 26.4 or later, expand the standalone app’s slider and choose 80%, 85%, 90%, 95% or 100%. Store version 1.1 uses a bundled Apple shortcut. Add it on first use, then check the result in Battery settings.

Which power sources does my selected mode affect?

In the standalone app, choosing a mode updates both the battery and external power settings. High Power is available on supported models. The recent high-energy apps list requires Apple silicon and macOS 27. Its scores compare apps within that list.

How can I measure CPU and GPU power?

On an Apple silicon Mac with chip power readings, open the standalone app’s gear menu, choose Peak Power Test and click Start Test. Both components run under load for up to 60 seconds. Each peak is the highest half-second average. You can stop at any time. Sleep or severe overheating also ends the test.

How do I try, buy or restore advanced controls?

Open the BatterVibe control panel from the gear menu in the App Store edition. Start the free 14-day trial or make a one-time ¥6 purchase in mainland China. Free monitoring remains available when the trial ends. Use Restore Purchases with the Apple Account you used to buy it.

How do I change languages?

Choose Language in the gear menu to follow the system or select one of eight interface languages. The change takes effect immediately. The website’s language menu opens the same page in the language you choose.

Read power from Terminal

With standalone 0.10.6 or store version 1.1 installed, set the alias below for your installation in Terminal. The first command opens the menu bar app if needed.

Standalone app

alias battervibe='/Applications/battery-mon.app/Contents/MacOS/battery-mon cli'

Mac App Store 1.1

alias battervibe='/Applications/BatterVibe.app/Contents/MacOS/BatterVibe cli'

Read status and change the display

battervibe status --json
battervibe menu net
battervibe --help

The standalone app also provides commands for closed-lid operation, power modes and high-energy apps. HDR and charge limits use the same hardware and access requirements as the app. For store charge limits, add the shortcut first and verify the result in Battery settings.

Exit code 3 means the result is unconfirmed. Code 4 means the request was sent. Read the current state before repeating the command.
