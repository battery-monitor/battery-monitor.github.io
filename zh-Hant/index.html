為 Web Coding 與 Vibe Coding 而生

把靈感，帶到更遠的地方。

從工作桌到陽光下，BatterVibe 讓你看清 Mac 的即時功率、為戶外螢幕增亮，讓長時間執行的開發任務繼續向前。

MacBook · macOS 13 或以上 · 功能支援因裝置與安裝管道而異

01 / 專注寫程式，也看清功率

這次建置，用了多少電？

AI 程式設計、瀏覽器預覽、建置測試，都在使用電量。將輸入功率、整機耗電或電池淨功率放在選單列，隨時了解 Mac 的用電狀態。

無需離開編輯器。讀數隨裝置、macOS 與供電狀態變化；不提供個別 App 的功率歸因。

02 / 把工作帶到自然裡

陽光正好，程式碼也清楚。

換一處風景，繼續做喜歡的東西。利用相容螢幕的額外亮度，在自然光下更從容地閱讀程式碼與查看網頁。

HDR 增亮
利用相容 XDR 螢幕的額外亮度空間，改善明亮環境下的觀看體驗。
按需開啟
需要額外亮度時開啟 HDR 增亮，回到室內即可關閉。

HDR 目前已在 MacBook Pro（Mac14,6）的內建 XDR 螢幕驗證；其他機型待驗證。增亮可能增加耗電。

03 / 把等待留給 Mac

闔上螢幕，任務繼續。

建置尚未結束，下載仍在進行。讓 Mac 留在桌面繼續處理長任務，等你回來接著做。

專案建置持續下載Agent 長任務

闔蓋執行需要官網安裝管道的背景元件與系統授權。Mac App Store 管道的一般防止睡眠不等於闔蓋執行。使用時請將 Mac 留在通風的固定桌面。

一套產品，一個控制面板

常用控制，在一起。

選單列適合隨時一瞥，獨立控制面板容納完整狀態與操作。BatterVibe 正在把兩者連成同一套體驗。
