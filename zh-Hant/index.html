電池詳情

這顆電池，現在能存多少電？

對照目前滿充容量與設計容量，再查看系統回報的健康度、循環次數和溫度。接上電源後，還能查看協商的功率上限、輸入電壓和電流。

返回概況即可查看時間估算。充電時顯示預計充滿時間。放電時，只要資料足夠，即使接著電源也能估算剩餘續航。

桌面控制

在陽光下寫程式，闔上螢幕繼續編譯。

獨立版將這台 Mac 支援的常用控制集中在概況中。

戶外螢幕亮度
相容的內建 XDR 顯示器可開啟 HDR 增亮，利用額外亮度。在室內可以關閉，以減少耗電。
闔蓋執行
開始編譯或下載後，開啟「闔蓋執行」。背景服務會讓工作繼續，關閉開關即可回復原先的睡眠設定。
充電與能耗
展開「充電上限」可選擇目標電量。手動選擇一次能耗模式，就會同時套用到電池與外接電源。

最大功耗測試

分別量出 CPU 與 GPU 的功耗峰值。

在齒輪選單開啟「最大功耗測試」。CPU 與 GPU 會同時執行高負載工作，最長 60 秒。視窗每半秒更新一次讀數，分別記錄本次測試的最高功耗。

支援晶片功耗讀數的 Apple 晶片 Mac 可在獨立版執行測試。你可以隨時停止。峰值會保留到下次測試或結束 App。

在終端機讀取功率

將電池狀態、功率與預計時間以 JSON 傳給指令稿，或直接透過終端機切換選單列讀數。
