為 Vibe Coding 打造的 Mac 選單列工具

Mac 變慢時， 先看看哪些核心在忙。

進行長時間編譯、執行本機模型或使用行動電源時，在選單列同時查看處理器負載、電池電量與即時功率。接著電源也能看出電池是在充電，還是在幫忙供電。

在 Mac App Store 查看 ↗ 比較版本與功能 ↓

適用於 macOS 13 或更新版本 · 中國大陸 Mac App Store

逐核心活動 ↓電池詳情 ↓桌面控制 ↓最大功耗測試 ↓

把每秒的負載，放在 20 秒裡看。

概況先顯示活躍度百分比。將游標移上去展開熱圖，按一下即可固定。每個 CPU 核心各佔一列，顏色越深，表示該秒忙碌的時間越長。

Apple 晶片獨立版將效能核心與節能核心分組，也會顯示 GPU 整體活動。選取 CPU 核心即可查看活動與所屬核心群組的頻率。GPU 顯示估算頻率，展開時也可查看可用的 CPU 和 GPU 瓦數。

電池詳情

電源夠不夠，看電池淨功率。

在概況對照輸入功率、整機耗電與電池淨功率。淨功率是負值時，電池正在補足供電差額。讀數足夠時，面板也會估算充滿或剩餘使用時間。

在電池詳細資料中比較充飽容量與設計容量，並查看健康度、循環次數和溫度。Mac 提供轉接器讀數時，也可查看協商功率、電壓及電流。

桌面控制

戶外看得清，工作繼續跑。

亮度、闔蓋運行、充電與能源模式都在獨立版概況內，需要時即可調整。

戶外螢幕亮度
相容的內建 XDR 顯示器可開啟 HDR 增亮，利用額外亮度。在室內可以關閉，以減少耗電。
闔蓋執行
開始編譯或下載後，開啟「闔蓋執行」。背景服務會讓工作繼續，關閉開關即可回復原先的睡眠設定。
充電與能耗
展開「充電上限」可選擇目標電量。手動選擇一次能耗模式，就會同時套用到電池與外接電源。

最大功耗測試

量測 CPU 與 GPU 的峰值功耗。

從齒輪選單啟動最大功耗測試。CPU 和 GPU 同時以高負載執行，最長 60 秒，每半秒更新並各自保留本次峰值。

支援晶片功耗讀數的 Apple 晶片獨立版可執行測試，也可隨時停止。結果保留至下一次測試或結束 App。

在終端機讀取功率

在終端機以 JSON 讀取電池和功率，或切換選單列上顯示的讀數。

查看命令列用法 →
battervibe status --json
battervibe menu net
